# Saloni Mehra — React Portfolio

Responsive portfolio built with React and Vite.

## Run locally
1. Install Node.js LTS from https://nodejs.org/
2. Extract the ZIP and open this folder in VS Code.
3. Open a terminal in this folder and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite, usually http://localhost:5173.

## Before publishing
- Verify that every project description matches work you have actually built.
- Update repository links in `src/App.jsx` to exact project URLs when available.
- Check your email, GitHub, and LinkedIn details.

## Deploy
Push to GitHub and import the repository at https://vercel.com/. Build command: `npm run build`; output directory: `dist`.
